Cloud Sync Setup

Step 1: Get Web Hosting

Create an account on any web hosting that supports PHP (like InfinityFree, 000webhost, or a paid hosting). Get your domain link (e.g., https://yoursite.com).

Step 2: Create the sync.php File

1. Log into your hosting account and open the File Manager.
2. Go to the htdocs or public_html folder.
3. Create a new file and name it exactly sync.php.
4. Edit this file, paste the server code (from the 'Get Server Code' button), and save it.
5. Important: Find the line $SECRET = 'enter your password'; and change it to your own strong secret key (e.g., $SECRET = 'MySecret123';).

Step 3: Create the sync_data.txt File

1. In the same folder, create another new file.
2. Name it exactly sync_data.txt. (Leave it completely empty).
3. Optional (Only if Upload fails): Some hosting providers require you to change file permissions. Right-click on sync_data.txt, find "Permissions" or "Chmod", and set it to 666. (Note: InfinityFree usually handles this automatically, so you can skip this step if you don't see the option).

Step 4: Configure in the DoDo App

1. Open the DoDo app. Tap the ⚙️ Settings icon.
2. Scroll down to the Cloud Sync section and tap Configure Sync.
3. Enter the details:
   Server URL: Your full link + /sync.php (e.g., https://yoursite.com/sync.php)
   Secret Key: The password you set in the PHP file
   Encryption Password: Create a new password. This will lock your data. (Do not forget this!)
4. Tap Save.

Step 5: Upload and Download

• Tap ⬆️ Upload to encrypt your data and save it to your server.
• Tap ⬇️ Download to get your data back on any device. (You must use the same Encryption Password to unlock it).
